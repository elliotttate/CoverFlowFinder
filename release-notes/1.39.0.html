What's New in 1.39

  • Runs on macOS 15 Sequoia again (1.29–1.38 required macOS 26).
  • Much smoother scrolling in Column, Icon and Masonry views in large folders (about 3–5× less work per frame).
  • Sizes for apps and folders: applications and other packages show their size, and the new Calculate all sizes setting (Settings › List) adds folder sizes, computed in the background like Finder.
  • Hidden files are dimmed when shown (⇧⌘.), and .DS_Store is never shown.
  • List view: only the column you sort by has a bold title, and the Name column can be as wide as you like.
  • Column view: drag a column's divider to resize it (⌥ resizes all), double-click it to fit the names; a tidier preview column that shows sizes and dates in large folders.
  • Go to Folder (⇧⌘G), and Move Item Here (⌥⌘V, hold Option in the Edit menu).
  • Progress and Stop for long copies, moves and Move to Trash; quitting during one asks first.
  • Double-clicking the path bar selects the whole path, ready to copy.

Fixes

  • Dropping files onto folders works in every view; dropping onto a file drops into its folder, and ⌥-dragging duplicates, like Finder.
  • ⌘⌫ in a text field (search, rename, path bar) deletes text instead of moving the selected files to the Trash.
  • No more stray mount/unmount sounds: they only play for volumes you can see in the sidebar.
  • Safer file operations: a move to another disk keeps the original until everything was copied, volumes can't be moved to the Trash, same-name conflicts are caught, and Undo/Redo work for copies, moves and renames.
  • Renaming follows Finder's rules for extensions (it asks before changing one) and handles “:” and “/” in names.
  • ZIP archives: browsing and copying out of malformed or malicious archives is safe, and big files inside them are copied without loading them into memory.
  • Quick Look, Cover Flow, selection, keyboard navigation, tabs and windows: many fixes for focus, double-clicks, stale previews and selection jumps.
  • iCloud badges and thumbnails update when a file downloads; folders that can't be opened say why.
  • Better performance and fewer stalls with large folders, network shares, Spotlight results and thumbnails.
