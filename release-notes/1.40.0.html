What's New in 1.40

  • More archive formats: browse ZIP, RAR, 7z, TAR and compressed archives with the bundled 7-Zip engine. No external archive utility is needed.
  • Password-protected, multipart and nested archives: enter passwords when opening or extracting, navigate inside nested archives, and keep multipart volumes together.
  • Extract archives from the File menu or right-click menu, including several archives at once. Choose the current folder, separate folders or another destination. Existing files are preserved with numbered names for conflicts.
  • Compress to ZIP or 7z from the File menu or right-click menu. Compress files or folders, preserve the originals, and use progress, cancellation and Undo / Redo.
  • Open as Archive for archive files with unfamiliar names.

Fixes

  • Move to Trash and Delete Immediately no longer stay greyed out after compression started with the search field focused. Command-Delete works on the newly selected archive.
  • Select All and other file commands consistently target the active browser window and pane after focus changes.
  • Quick Look ignores outdated archive previews, and background archive thumbnails avoid unnecessary extraction and repeated password prompts.

Browsing inside archives is read-only. RAR support is for browsing and extraction; archive creation supports ZIP and 7z.
