# Archive support

CoverFlowFinder builds and embeds SevenZipKit from the checked-in `Vendor/SevenZip` sources. Ordinary unencrypted ZIP files using Stored or Deflate retain the native reader. Other ZIP methods, encrypted ZIP, RAR, 7z, TAR, compressed streams, multipart sets, and other engine formats use SevenZipKit. No external archive utility is needed at runtime.

`SevenZipArchiveBackend` confines all engine sessions and their destruction to one serial queue. The eight-session cache is keyed by file revision, including sibling volumes. Passwords live only in these sessions; interactive actions use a secure field, and background previews never request a password. Wrong-password errors clear the cached extraction password.

The added `SZArchiveStreams` bridge enumerates raw item indices and sends selected decoded bytes to CoverFlowFinder's existing safe writer. It never asks the engine to create output paths. It checks every per-item operation result, including a failed CRC when the overall engine call succeeds. Integrity testing also rejects header error flags on archives that opened successfully. Decoder memory properties and callbacks are capped at 512 MiB where the handlers support them; 7z metadata headers have a separate 128 MiB cap. Listings are capped at 250,000 entries. These bounds are not a process-wide memory sandbox.

Copy-out keeps path confinement, atomic verified files, actual and declared byte limits, permission sanitization, collision reporting, cancellation cleanup, and leases. Safe relative symbolic links are retained; unsafe link targets become inert text files. Archive hard links copy the referenced member's data into a regular file. Nested extractions inherit quarantine from the outer source.

Nested archives are materialized one selected member at a time and represented by logical locations with parent navigation and revision-aware preview keys. Depth is limited to 16 archive levels. Up selects the archive just left; Back and breadcrumb navigation preserve the nested locations. Compressed TAR files expose their TAR member, which can be entered in the same way.

Quick Look prepares the selected file when the panel is requested or already visible. Selection updates ignore stale completions and do no extraction while the panel is closed. Thumbnails deduplicate requests and honor request-owner cancellation. Background member extraction is limited to 32 MiB; engine work additionally stops after two seconds or 128 MiB of decoded work. Expensive members in large solid archives can therefore keep their file icon. Explicit opening, previews, and copy-out support larger members with progress and cancellation.

Use File → Open as Archive for an unfamiliar filename. File and context menus offer Extract Here, Extract to a named folder (separate folders for a batch), and Extract to Folder (one chosen folder for a batch). The full archive uses the safe writer in private staging, then verified items are published with keep-both collision handling and the existing file-operation journal for Undo / Redo. Cancelling removes unpublished staging; already published items stay and can be undone. Compressed TARs unpack through their TAR member automatically when extracting. Integrity checks remain internal to the engine and regression tests. Keep multipart siblings together; open the first RAR/7z volume or the main ZIP file.

File and item context menus also offer Compress to ZIP and Compress to 7z for local files and folders. `SZUpdater` creates a fresh archive in private staging beside the destination, using literal source paths, relative member names, stored symbolic links, Deflate for ZIP and LZMA2 with a 16 MiB dictionary for 7z. Compression uses level 5 and two threads. Any reported source scan/read errors reject the archive before publication. Completed archives are published with keep-both names and `.created` journal entries, so Undo / Redo never moves the originals. Cancellation removes unpublished staging. Selecting a folder and one of its children includes that child once; ambiguous root names and destinations inside selected folders are rejected. Creation shares the engine queue with browsing and needs no external utility.

`Tests/run-archive-regression.sh` compiles the production Swift sources and exercises format, password, nested/multipart, safety, navigation, Quick Look, and thumbnail behavior. `Tests/run-selection-command-regression.sh` protects the existing command routing. See `Tests/README.md` for prerequisites and fixture provenance.

SevenZipKit is a dynamic framework with retained LGPL/component/RAR notices and corresponding source in this repository. Notices are bundled under `Contents/Resources/ThirdPartyNotices/SevenZip`. Vendor modifications are listed in `Vendor/SevenZip/PATCHES.md`. RAR support is decompression only.
